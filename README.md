🔐 Password Strength Checker

A Python program that checks the strength of a password using different security rules.

🚀 Features

- Checks password length
- Detects uppercase & lowercase letters
- Detects numbers
- Detects special characters
- Classifies password as Weak, Medium, or Strong

▶️ How to Run

1. Open terminal / command prompt  
2. Navigate to project folder  
3. Run the command:  

```
python password_checker.py
```  
📌 Example Output
```
Enter your password: abc
Weak Password ❌

Enter your password: Yash123
Medium Password ⚠️

Enter your password: Yash@12345
Strong Password 🔥
```
